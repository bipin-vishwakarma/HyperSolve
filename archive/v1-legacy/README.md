# 📦 HyperSolve v1.0 Legacy Archive

This directory contains the original monolithic proof-of-concept scripts from HyperSolve v1.0:

- **`full_auto.py`**: The original single-file prototype containing embedded CSS selectors, basic tab switching, and console logging.
- **`start_all.bat`**: The original batch runner for launching Chrome with debugging and running `full_auto.py`.

---

## ⚠️ Deprecation Notice

These files are preserved for historical reference and backwards compatibility.

For production use, please use **HyperSolve v2.0**:
- **Desktop Dynamic Island HUD**: Run `run_desktop.bat` (or `python desktop_main.py`).
- **Autonomous Chromium Engine**: Run `run_hypersolve.bat` (or `python main.py`).
